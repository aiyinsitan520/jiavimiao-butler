# 贾维喵管家 0.4.8 测试版

Mac 主窗口和独立笔记窗口改用 macOS 原生标题栏，关闭、最小化和全屏按钮由系统在左上角显示，遵循系统红黄绿样式及交互。移除 Mac 页面右上角重复的 Windows 式窗口按钮，应用工具栏继续保留搜索、快捷框和笔记工具。快捷框和桌面组件保留原来的浮动卡片形式。

主窗口处于全屏时不再覆盖正常窗口的位置和尺寸记录。独立笔记的系统关闭事件继续先处理待保存编辑，再销毁窗口；主窗口关闭后继续在菜单栏运行，可从 Dock 或菜单栏重新打开，退出应用使用应用菜单或菜单栏的“退出”。

同时包含开发预览更新提示修正：预览版不再错误显示“重启更新”；正式安装版仍在本人确认后安装。保留 0.4.7 的自选资料目录、Agent 阅读快照及待办/灵感快捷键。

前端构建、611 项前端检查、Windows 原生测试及 34 项隔离浏览器窗口检查已通过。浏览器检查覆盖两类窗口各三种尺寸、重复按钮隐藏、Windows 按钮绑定和关闭前保存顺序，不等同于 Mac 原生窗口验收。Mac 真机红黄绿按钮、全屏切换、多显示器、安装升级及资料保留仍需验收。

Windows x64 安装包；Mac Apple Silicon DMG 与签名 app.tar.gz 更新包。0.4.3 及以后可在“软件更新”检查测试版更新，下载校验后由本人确认安装；更早版本首次需手动安装。Mac 尚未公证，真实模型与微信需本人验收。
